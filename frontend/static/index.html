Security Controls

Local First

  • Face data remains on the device
  • Runtime files are gitignored
  • No cloud account required
Active

Embedding Protection

  • Fernet encryption when available
  • SHA-256 integrity checksum
  • Legacy embedding migration

Configurable Liveness

  • Optional blink detection with dlib
  • Fail-open demo mode
  • Dedicated landmark model path
